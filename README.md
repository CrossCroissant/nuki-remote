# Nuki Remote – Home Assistant Add-on

Geschützte Fernsteuerung der Nuki-Haustür als eigenständige Webseite (PIN-Sitzung + zentrale Freigabe).

## Installation

[![Repository zu Home Assistant hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FCrossCroissant%2Fnuki-remote)

1. Auf den Button klicken (oder unter *Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories*
   die URL `https://github.com/CrossCroissant/nuki-remote` eintragen).
2. **Nuki Remote** installieren, Optionen prüfen und starten.

Details siehe [nuki_remote/DOCS.md](nuki_remote/DOCS.md).
